Hi, I'm **Mohammad Rabba**, a Computer Science graduate passionate about building practical software, backend services, and AI-powered applications.

I enjoy solving technical problems, integrating APIs, troubleshooting systems, and turning ideas into reliable software.

- 🔗 **API Integration:** Interested in connecting services, debugging workflows, and building reliable integrations.
- ☁️ **Infrastructure & Deployment:** Exploring Redis, Supabase, Linux, Docker, and cloud deployment workflows.
- 📈 **Continuous Learning:** Improving my skills in software architecture, maintainable code, and scalable application design.

**My goal:** Build useful software that solves real problems and delivers a great user experience.
